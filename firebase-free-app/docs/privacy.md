# Privacy and Data Retention

The SPX Network Development App stores approval request data, user profiles, documents, notifications, and audit logs in Firebase.

Data retention:

- Active requests are kept while they are pending or in use.
- Completed, rejected, and cancelled requests are archived after 6 months.
- Archived data is retained for administrative and audit purposes.
- Audit logs are not editable or deletable.

Access:

- Users only see requests they are assigned to or tagged in.
- Administrators can see all requests and logs.

Privacy:

- Only @spxexpress.com accounts can use the app.
- Email and name are used for identification and notifications.
- Documents are treated as private and only shared with request participants and admins.

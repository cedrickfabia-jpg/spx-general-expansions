# HOD Approval Template Mapping

Status: Finalized to the requester field list provided by the user.

The requester form contains only the fields below. Every field except Sublease
Mark-Up %, Reason for Subleasing, and Other Concerns is required before the
request can be submitted.

| Request field | Web form field | Validation | Completed by |
| --- | --- | --- | --- |
| Hub Name | Hub Name | Required | Requester |
| Region (all uppercase) | Region | Required, uppercase | Requester |
| Pipeline | Pipeline | Required dropdown: Yes / No | Requester |
| Facility Type | Facility Type | Required dropdown: Hub / RC / MFM / SOC / Parking / DOP | Requester |
| Expansion Type | Expansion Type | Required dropdown: Split / New Coverage / Transfer / Renewal / Renewal+Downsizing | Requester |
| Utilization | Utilization | Required textarea | Requester |
| Lease Type | Lease Type | Required dropdown: Direct Lease / Sublease | Requester |
| Sublease Mark-Up % | Sublease Mark-Up % | Optional | Requester |
| Reason for Subleasing | Reason for Subleasing | Optional; N/A if not a sublease | Requester |
| Facility Work | Facility Work | Required dropdown: BTS Ground Zero / BTS Fit-Out / Facility Ready for Fit-Out | Requester |
| Location Score | Location Score | Required, xx / 100 | Requester |
| Due Diligence Status | Due Diligence Status | Required; In Progress with MM-DD-YYYY target or Completed; list lacking DD items | Requester |
| Rent Benchmark | Rent Benchmark | Required textarea | Requester |
| Escalation | Escalation | Required | Requester |
| CPO | CPO | Required textarea | Requester |
| Security Deposit | Security Deposit | Required | Requester |
| Renovation | Renovation | Required dropdown | Requester |
| Renovation Type | Renovation Type | Required dropdown | Requester |
| Other Concerns | Other Concerns | Optional | Requester |

Required uploads before submission:

- FF Approval
- CPO Table
- Hub Location Scoring

Optional uploads:

- Optional file 1
- Optional file 2
- Optional file 3

Only PDF files are accepted for uploads.

Routing note: the requester selects CPO Budget Status from a dropdown. Within
budget routes to HOD 1 only; above budget routes to HOD 1 first, then HOD 2.
